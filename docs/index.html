想买的先蹲着，
降价了微信喊你

淘宝/京东促销信息散落在邮件、短信、App 推送里，没人有空天天比价。把商品链接丢给蹲价助手，它替你盯历史价格曲线，到位了推送通知。

📉 历史价曲线

联盟 API 定时快照，90 天价格走势一眼看穿"假折扣"。

🎯 目标价提醒

设个心理价位，到了就推微信订阅消息，一天最多一条不轰炸。

🔍 双平台覆盖

淘宝、京东官方联盟接口取数，不爬页面，稳定合规。

三步上手

1

粘贴商品链接
加入蹲价清单

2

看历史价曲线
设目标价或降幅

3

授权订阅消息
降价自动推送
